# Edward Lau — Portfolio Figma Import Kit

This kit recreates the current portfolio structure as Figma-ready SVG design boards.

Included:
- Home — Desktop
- About — Desktop
- Projects — Desktop
- Skills & Resume — Desktop
- Contact — Desktop
- Home — Mobile
- Design System / Components

## Import into Figma
1. Create a new Figma Design file.
2. Drag all `.svg` files into the canvas, or use File > Place image.
3. Keep each SVG as one page/board, then use **Frame selection** if you want native Figma frames.
4. Add prototype connections:
   - Home / View Projects -> Projects
   - Home / Contact Me -> Contact
   - Navigation items -> matching pages
   - Project cards -> Project detail modal / case study
   - Contact CTA -> Contact form
5. Create components for buttons, pills, cards and navigation using the Design System board.

The visual language follows the portfolio's dark neon glass style with cyan, purple and pink accents.

Note: this is a Figma-importable design kit, not a native `.fig` export. Native Figma file creation requires a connected Figma workspace.
